================================================================
  VisoMaster TRT Portable 整合包
  ----------------------------------------------------------------
  全离线 / 全移植 / 不依赖系统任何运行时
  仅需要 NVIDIA 显卡驱动 (支持 RTX 20xx ~ RTX 50xx)
================================================================

【快速开始】

  1. 解压主包到任意目录 (路径不要有中文 / 空格)
  2. 解压模型包 VisoMaster-Models-Core.7z 到同一目录, 合并 models/
  3. 双击 Start.bat
     - 弹出图形化启动器窗口
     - 自动检测环境 / 模型 / 引擎状态
     - 点击 [启动主程序] 即可使用 (首次会自动编译 TRT 引擎)

【启动器界面说明】

  ┌──────────────────────────────────────────────┐
  │  状态卡片 (运行环境 / 模型状态 / TRT 引擎)    │
  │  ───────────────────────────────────────    │
  │  📥 下载模型     ⚙️ 编译引擎    🔍 重检环境   │
  │  🛠 高级设置     📂 打开目录    🧹 清理缓存   │
  │  ───────────────────────────────────────    │
  │           [ 启 动 主 程 序 ]                  │
  │  ───────────────────────────────────────    │
  │  运行日志输出区                                │
  └──────────────────────────────────────────────┘

  所有操作都是图形按钮, 不需要命令行。

【重要: 关于 TensorRT 加速】

  本整合包 TRT 加速分两种路径, 用户需要知道:

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  路径 A: LivePortrait (表情驱动) 功能
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • 启动器 [编译 LP 引擎] 编出的 6 个引擎, 主程序直接加载
  • 用之前在启动器点 [预热 LP 引擎], 主程序不卡顿

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  路径 B: 换脸 / 检测 / 修复 / 超分等其它功能
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • 由主程序的 ORT TensorRT EP 自己编译
  • 操作: 主程序里 [高级设置] -> Providers Priority 选 "TensorRT"
  • 第一次跑视频会卡 1~3 分钟 (ORT 在编译每个用到的模型)
  • 编译产物自动缓存到 tensorrt-engines\ 目录
  • 第二次起秒响应
  • 之后可以切到 "TensorRT-Engine" provider, 只加载缓存不重编

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  小白用户最简流程
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 启动器 [编译 LP 引擎] (3 分钟, 一次性)
  2. 启动器 [预热 LP 引擎] (可选)
  3. [启动主程序] -> 高级设置选 "TensorRT" -> 加载视频
  4. 第一次跑卡几分钟正常, 等就好, 别关程序
  5. 之后再切 "TensorRT-Engine" 就一直快了

【常见操作】

  下载模型:  点 [📥 下载模型] -> 勾选要下载的包 -> 确定
            自动多镜像 fallback + 断点续传

  编译引擎:  点 [⚙️ 编译引擎] -> 选择模式 (核心/全部/重编)
            首次约 10~25 分钟, 之后秒启

  切换换脸/修复方式:
            点 [🛠 高级设置] -> 性能优化开关
            可关闭/开启各项 TRT 优化, 方便对比

【启动器无法打开?】

  如果双击 Start.bat 后没有任何窗口弹出, 可能是 PySide6 / DLL 加载失败。
  解决方案:
    1. 双击 _internal\diagnose.bat (诊断模式)
    2. 该窗口会前台显示完整错误日志
    3. 根据日志判断是缺什么或 DLL 路径问题

【环境锁定】

  Python              3.10.13 (嵌入式, 无需安装)
  CUDA Runtime        12.8 (pip 包内, 不依赖系统 CUDA)
  cuDNN               9.5
  PyTorch             2.7.0+cu128
  TensorRT            10.7.0
  ONNX Runtime GPU    1.21.0
  GUI 框架            PySide6 6.8

【目录结构】

  python\          嵌入式 Python + 全部依赖
  app\             VisoMaster 源码 (已应用 TRT 优化)
  models\          ONNX 模型 (启动器下载到这里)
  engines\         TRT 编译产物 (启动器编译到这里)
  workspace\       用户工作区存档
  output\          默认输出
  tmp\             临时缓存
  _internal\       启动器内部文件 (不要手动改)

  Start.bat        ★ 唯一入口, 双击即可

【50xx 显卡需要额外操作吗?】

  不需要。本包 cu128 + TRT 10.7+ 原生支持 Blackwell (sm_100/120)。
  RTX 5070/5080/5090 开箱即用。
